## v2 · 多用户知识点复习系统（当前版本）

### 1. 一句话定义

> **为【需要复习备考的你】,在【手机/平板/电脑都能用】场景,解决【考点多、想按遗忘曲线安排复习、又怕漏掉没学过的内容】问题,产出【一个部署在腾讯云、多账号、多设备同步的知识点复习系统】。**

### 2. 成功标准（可验证）

- [x] 注册/登录可用，注册需口令，多账号进度隔离
- [x] 卡片式复习：题目 + 认识/模糊/忘记三档自评，按钮显示「X天后」
- [x] 阶梯算法：认识进档、模糊退档、忘记重置（9 档 1→180 天）
- [x] 今日到期已学知识点全部推送、不限量
- [x] 每次混入约 30% 未学知识点，仅提醒、可评价但不转已学
- [x] 「加入复习」手动把未学转已学
- [x] 复习范围（科目）设置，作用于复习与出题
- [x] 统计页展示总量/已学/待复习/累计 + 各档分布 + 自评分布
- [x] 保留随机出题（不记录进度）
- [x] 手机/平板/电脑响应式
- [x] 173 项自动化测试通过（算法 31 + 接口 76 + 部署 37 + UI 29）

### 3. 架构 / 模块

```
浏览器（web/：原生 HTML/CSS/JS，响应式）
   │  REST + HttpOnly Cookie 会话
   ▼
Node.js 服务（server/server.mjs，node:http，零 npm 依赖）
   ├── auth.mjs    注册/登录/scrypt 哈希/会话
   ├── review.mjs  阶梯算法、今日队列、30% 未学提醒
   ├── db.mjs      node:sqlite 建表与查询
   └── seed.mjs    data/*.json → 题库表
   ▼
SQLite 单文件（默认 var/learning.db，生产 /var/lib/random-question/learning.db）
```

**数据流**：`inputs/*.docx` →(import_docx.py 清洗)→ `data/*.json` →(seed.mjs)→ SQLite 题库表 → 复习队列 API → 前端卡片

### 4. 数据库设计

| 表 | 作用 | 关键字段 |
| --- | --- | --- |
| `users` | 账号 | username 唯一、password_hash、salt |
| `sessions` | 会话 | token 主键、expires_at |
| `questions` | 题库（全局共享） | subject、text、answer |
| `progress` | 每用户每题的进度 | user_id+question_id 主键、status(new/learned)、stage、next_review |
| `review_log` | 自评流水（统计用） | rating、is_new、day |
| `settings` | 用户设置 | subjects（JSON 数组，复习范围） |

### 5. 复习算法（阶梯制）

间隔阶梯 `STAGES = [1,2,4,7,15,30,60,90,180]`（天），下标即 stage：

| 自评 | stage 变化 | 下次间隔 |
| --- | --- | --- |
| 认识 know | `min(stage+1, 8)` | 阶梯下一档 |
| 模糊 vague | `max(stage-1, 0)` | 阶梯上一档 |
| 忘记 forget | `0` | 1 天 |

（v2.1 起，复习队列不再混入未学内容，未学内容由学习页负责——详见 5.1 / 5.2。）

### 5.1 学习页算法（v2.1 新增）

- 取 N 个未学知识点，N 由用户输入（默认 20，可选 10/20/30/50）
- 三档自评**任一选择都标记为已学**，只是首次复习间隔不同：
  以第 1 档为基准套用评价 → 认识 2 天、模糊 1 天、忘记 1 天
- 已学过的题不会再次出现在学习列表；重复提交按复习规则处理（返回 `alreadyLearned=true`，不重复计入）

### 5.2 复习页算法（v2.1 调整）

**复习队列** = 所有**已学**且 `next_review <= today` 的知识点，全部列出、不限量。
（v2 的"混入 30% 未学提醒"已移除，未学内容改由学习页负责。）

**进度保存**：学习 / 复习的当前批次与下标保存在浏览器 localStorage，按天有效；
切换页面不重置，刷新页面也不丢，跨天自动作废重排。

### 6. 关键决策记录（v2，开发前与你逐项确认）

| 事项 | 决策 |
| --- | --- |
| 部署目标 | 用户自备的腾讯云服务器 |
| 数据存储 | 服务器数据库（多设备同步），非浏览器本地存储 |
| 技术栈 | Node.js 24（内置 node:sqlite + node:crypto），零 npm 依赖 |
| 复习算法 | 三档动态调整的阶梯制（同参考图效果） |
| 推送方式 | 网页内「今日待复习」，到期全推、不限量 |
| 卡片内容 | 只显示题目文本，心中回忆后自评 |
| 原随机出题 | 保留，作为独立 tab，不记录进度 |
| 鉴权 | 注册/登录 + 注册口令；各账号进度独立 |
| 范围设置 | 放在「我的」里设置（不单设 tab） |
| 初始状态 | 495 题全部初始为未学 |

### 6.1 v2.1 变更（应用逻辑调整）

| 事项 | 旧（v2） | 新（v2.1） |
| --- | --- | --- |
| 未学内容入口 | 复习页混入 30% 提醒 +「加入复习」按钮 | **独立「学习」页** |
| 学习批量 | 无（30% 自动） | **人工输入，默认 20** |
| 未学评价结果 | 只记流水，不转已学 | **三档任一都转为已学** |
| 复习队列 | 到期已学 + 30% 未学提醒 | **仅到期已学** |
| 导航 | 复习 / 出题 / 统计 / 我的 | **学习 / 复习 / 出题 / 统计 / 我的** |
| 切页行为 | 每次重新拉取、从第 1 张开始 | **保持当前批次与进度** |

### 7. 本期不做

- 不判对错（三档为自评）
- 不自动展示答案（`answer` 字段预留）
- 不做推送通知（无 App 通知/微信/邮件）
- 不做 SM-2 / FSRS 等其它算法
- 不做管理后台

## v1 · 静态随机出题页（历史版本，保留备用）

**定位**：纯前端单文件、无后端、可放 GitHub Pages 的按科目随机出题工具。

| 事项 | 决策 |
| --- | --- |
| 交付形态 | 浏览器网页应用，纯前端单文件 |
| 出题范围 | 全部混合，不区分题型 |
| 题库 | docx 清洗成 JSON 后内嵌进 HTML |
| 加题 | 编辑 JSON 或导入 docx 后重新打包 |
| 章节 | 不要章节，纯科目+题目 |
| 答案 | 预留字段但出题时隐藏 |
| 部署 | GitHub Pages 静态托管 |

产物：`outputs/出题工具.html`、`index.html`（由 `src/build.mjs` 生成）

> v2 已把「随机出题」内置为应用的一个 tab；v1 静态版本保留，仍可用于无服务器的轻量场景。
