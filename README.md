# 知识点学习与复习系统

> 为【需要复习备考的你】，在【手机 / 平板 / 电脑都能用】的场景，解决【题库里有一批考点、想先系统学一遍、再按遗忘曲线安排复习】的问题，产出【一个部署在自己服务器上、多账号、多设备同步的知识点学习与复习系统】。

**核心特点**

- 🌱 **学习页**：只展示**未学**知识点卡片，一次学多少个**由你输入**（默认 20）；「认识 / 模糊 / 忘记」**任选一个都算学会**，该知识点立即转为已学并开始排复习计划
- 📖 **复习页**：只针对**已学**知识点，按艾宾浩斯式间隔阶梯排出今日到期的全部内容（不限量）
- 📈 **阶梯计划**：`1→2→4→7→15→30→60→90→180` 天；复习时认识进档、模糊退档、忘记重置
- 💾 **进度不丢**：学习 / 复习的当前进度会保存——**切换到其它页面再回来不会重头开始**，刷新页面也不丢
- 👥 **多账号 + 服务器同步**：注册登录，各账号进度独立，手机平板电脑共用一份进度
- 🎲 **保留随机出题**：自由练习模式，不记录进度
- 📦 **零外部依赖**：只用 Node.js 内置模块（`node:http` / `node:sqlite` / `node:crypto`），无需 `npm install`、无需数据库服务
- 🔒 **基础安全**：密码 scrypt 加盐哈希、HttpOnly 会话 Cookie、注册口令、登录失败限流、安全响应头

## 技术栈

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 后端 | Node.js ≥ 24（原生 `node:http`） | 零 npm 依赖 |
| 数据库 | SQLite（Node 内置 `node:sqlite`） | 单文件、免安装、易备份 |
| 鉴权 | `node:crypto` scrypt + HttpOnly Cookie 会话 | 密码加盐哈希，注册需口令 |
| 前端 | 原生 HTML / CSS / JS | 响应式，手机平板自适应 |
| 部署 | systemd + 腾讯云服务器 | 开机自启、崩溃自动重启 |

## 快速开始（本地）

```bash
# 1. 导入题库到数据库（读取 data/*.json）
node server/seed.mjs

# 2. 启动服务
REGISTER_CODE=my-code node server/server.mjs
# 打开 http://127.0.0.1:8080/
```

环境变量：

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `PORT` | `8080` | 监听端口 |
| `HOST` | `0.0.0.0` | 监听地址；配合 Nginx 可设 `127.0.0.1` |
| `REGISTER_CODE` | `ask-owner` | 注册口令（**生产环境必须修改**） |
| `DB_PATH` | `<项目>/var/learning.db` | 数据库文件路径 |
| `AUTH_MAX_FAILS` | `10` | 同 IP 时间窗内允许的登录/注册失败次数 |
| `AUTH_WINDOW_MS` | `600000` | 限流时间窗（毫秒） |

## 学习与复习机制

系统分成**两个独立页面**：

### 🌱 学习页 —— 学新知识点

- 只展示**未学**知识点，一次学多少个由你输入（**默认 20**，可选 10/20/30/50）
- 卡片上三档按钮「认识 / 模糊 / 忘记」：**选任意一个都会把该知识点标记为「已学」**，并立刻进入复习计划
- 三种选择只影响**首次复习的间隔**：

| 学习时选择 | 首次复习间隔 |
| --- | --- |
| **认识**（已经会） | 2 天后 |
| **模糊** | 1 天后 |
| **忘记** | 1 天后 |

### 📖 复习页 —— 按遗忘曲线巩固

- 只针对**已学**知识点，列出所有 `next_review <= 今天` 的到期内容，**不限量**
- 复习时三档自评按阶梯推进：

| 复习时选择 | 效果 |
| --- | --- |
| **认识** | 前进一档（间隔变长） |
| **模糊** | 退回一档 |
| **忘记** | 重置回第 1 档 |

阶梯共 9 档：第1档 1 天 → 第2档 2 天 → 第3档 4 天 → 第4档 7 天 → 第5档 15 天 → 第6档 30 天 → 第7档 60 天 → 第8档 90 天 → 第9档 180 天。

### 💾 进度保存

- 学习 / 复习的**当前批次与进度位置都会保存**
- 切到「统计」「我的」等其它页面再切回来，**继续原来的位置，不会重头开始**
- **刷新页面 / 关掉浏览器再打开也不丢**（按天保存在浏览器本地，跨天自动作废重排）

### 抽题范围

在「我的 → 学习与复习范围」勾选科目并保存；**不勾选 = 全部科目**。该范围同时作用于「学习」「复习」和「出题」。

## 部署到腾讯云

完整步骤见 **[`deploy/部署说明.md`](deploy/部署说明.md)**。

一句话版（在本机 Windows 执行）：

```powershell
pwsh -File deploy/deploy.ps1 `
  -ServerHost 你的服务器IP `
  -SshKey "$env:USERPROFILE\.ssh\id_ed25519" `
  -RegisterCode "你的注册口令"
```

脚本会：本地跑测试 → 打包 → 上传 → 服务器上装 systemd 服务并启动 → 验证健康检查。

记得在**腾讯云安全组放行应用端口**（默认 8080），手机才能访问。

# 方式 A：改 inputs/*.docx 后重新解析（脚本内含错别字修正与清洗规则）

node server/seed.mjs

## 功能清单

- [x] 注册 / 登录（注册口令拦截陌生人），多账号进度隔离
- [x] **学习页**：只展示未学知识点，数量人工输入（默认 20），三档任一选择都转为已学
- [x] **复习页**：只针对已学知识点，按遗忘曲线排出今日到期内容（不限量）
- [x] 艾宾浩斯阶梯：复习时认识进档 / 模糊退档 / 忘记重置
- [x] **进度保存**：切页不重头开始，刷新页面也不丢
- [x] 学习与复习范围（科目）设置，作用于学习、复习与出题
- [x] 统计页：总题数 / 已学 / 未学 / 今日待复习 / 累计学习 / 累计复习 + 间隔分布 + 自评分布
- [x] 随机出题（不记录进度）
- [x] 手机 / 平板 / 电脑响应式，底部导航带到期角标
- [x] 多设备同步（服务器数据库）

### 明确不做

- 不判对错（三档为**自评**，系统不判断答案对错）
- 不做答案自动展示（题库 `a` 字段预留）
- 不做推送通知（网页内"今日待复习"即触发方式）
- 不做记忆曲线以外的算法（如 SM-2 / FSRS）

## 已知限制

- 题库条目多为考点式短语（如"无土栽培"），属原始 docx 数据特征。
- 数据库为 SQLite 单文件，适合个人 / 少量账号；若要多用户高并发需换数据库。
- 「累计学习次数」统计的是学习阶段的三档评价次数；「累计复习次数」统计复习阶段的评价次数。
- 学习 / 复习的进度保存在**浏览器本地**（按天有效），因此同一账号在**另一台设备**上看不到"当前进行到第几张"，但已学状态与复习计划都在服务器上、两端一致。

## FAQ

**Q：学习时点「模糊」或「忘记」，这个知识点算学过吗？**
A：算。学习页三档**任选一个都标记为已学**并进入复习计划，区别只在首次复习的间隔（认识 2 天，模糊/忘记 1 天）。

**Q：切到别的页面再回来，进度会重来吗？**
A：不会。学习 / 复习的当前批次和位置都会保存；刷新页面也不丢。想重新开始可点完成卡片上的「再学一批」或复习页的「重新检查」。

**Q：今日一个到期知识点都没有，怎么办？**
A：说明还没有到期的已学内容。去「学习」页继续学新知识点，明天就会有内容进入复习。

**Q：换手机后进度还在吗？**
A：已学状态和复习计划会同步（存服务器），用同一账号登录即可。当前正在进行的批次位置存在设备本地，换设备会从该设备的批次重新开始。

**Q：需要云服务器吗？能用 GitHub Pages 吗？**
A：本系统需要后端 + 数据库，所以需要一台能跑 Node 的服务器（腾讯云轻量即可）。纯静态的「遗留版本」可以放 GitHub Pages，但不带账号与同步。
