# 随机出题 · 按科目练习

> 为【需要复习备考的你】，在【手机 / 平板 / 电脑都能用】的场景，解决【题库里有一批考点、想按科目随机抽题自测】的问题，产出【一个纯前端、无服务器、可部署到云、按科目随机出题的单文件网页工具】。

**核心特点**：只出题、不判对错、题目在同一次出题中不重复；可部署到 GitHub Pages 等静态托管，手机平板打开网址即用；本地双击也能用。

---

## 快速开始

> 项目已为你打包好，**直接用现成产物即可**，无需构建。你只需要把产物放到网页托管上。

### 1. 直接使用（已打包产物）

打开 `outputs/出题工具.html`：
- **电脑**：双击即可在浏览器打开。
- **手机 / 平板**：把该文件部署到静态托管（见下文「部署」），或把文件发到设备后用浏览器打开。

### 2. 重新生成产物（改完题库后）

```bash
node src/build.mjs
```

它会读取 `data/*.json`，合并内嵌进 `src/template.html`，覆盖写出 `outputs/出题工具.html`。

### 3. 从 docx 重新导入题库（有新 docx 时）

```bash
python scripts/import_docx.py
```

它会解析 `inputs/` 下的 docx，清洗错别字、去章节标记、去残字，生成 `data/<科目>.json`。之后再 `node src/build.mjs` 即可。

### 4. 运行测试

```bash
node tests/test_pick.mjs    # 出题算法：随机、不重复、数量
python tests/test_clean.py  # 清洗逻辑：去章节、修错字、去残字
```

## 题库数据格式

`data/<科目>.json` 结构：

```json
{
  "subject": "机械设计",
  "questions": [
    { "q": "连接部分", "a": "" },
    { "q": "机器设计的基本要求", "a": "" }
  ]
}
```

- `q`：题目文本（含填空下划线 `____`，出题时展示）。
- `a`：答案 / 备注（**预留字段，出题时隐藏**，以后可填）。

> **约定**：不加章节标签；每题只保留「科目 + 题目(+可选答案)」。

## 部署到网页（方案二 · 云静态托管）

产物 `outputs/出题工具.html` 是**纯静态单文件**，无后端依赖，适合任意静态托管。这里以 **GitHub Pages** 为例（免费、无需云服务器）。

1. 新建一个 GitHub 仓库（或复用已有仓库），把 `outputs/出题工具.html` 上传进去（可命名为 `index.html` 以便根路径访问）。
2. 仓库 `Settings → Pages → Source` 选择该分支 + `/ (root)`，保存。
3. 等待一两分钟，GitHub 会给一个公网地址，形如：
   `https://你的用户名.github.io/仓库名/`
4. **手机 / 平板 / 电脑浏览器打开这个网址即用**，且更新题库后重新上传文件即可。

> 也支持任何静态托管（Netlify / Vercel / 网盘静态页 / 自有 Nginx），把 `出题工具.html` 放上去即可。
> **日常使用不需要任何服务器 / 后端进程**，题库内嵌在 HTML 里。

### 想局域网临时用（不部署公网）

在 `outputs/` 目录起一个极简静态服务，手机连同一 WiFi 用电脑 IP 访问：

```bash
python -m http.server 8000 --directory outputs
# 手机浏览器访问 http://<电脑局域网IP>:8000/出题工具.html
```

## 添加 / 修改题目（加题频率低）

两种方式任选：

- **方式 A · 导入新 docx**：把新 docx 放进 `inputs/`，在 `scripts/import_docx.py` 的 `SUBJECTS` 里加一行科目映射，然后：
  ```bash
  python scripts/import_docx.py && node src/build.mjs
  ```
- **方式 B · 直接编辑 JSON**：编辑 `data/<科目>.json` 增删题目，再：
  ```bash
  node src/build.mjs
  ```

## 已知限制 / 已知问题

- 原 docx 里部分条目本身就是考点名词（如"无土栽培"），作为题面较简略，属忠实原始数据。
- 计算机科目中"数据库""IP"两个词条在源文档里出现两次，故题库中存在完全相同的两题（出题时按会话内去重处理）。
- 题库量约 497 题，全部内嵌于单个 HTML（约 36KB），体积很小，加载快。

## 常见问题（FAQ）

**Q: 为什么手机不能"双击打开"本地文件？**
A: 手机浏览器不像电脑能直接打开硬盘里的文件。手机端请用「部署到网页」或「局域网」方式通过网址访问。

**Q: 需要云服务器吗？**
A: 不需要。产物是纯静态文件，GitHub Pages 等静态托管即可，免费且无需维护服务器。

**Q: 想判对错 / 显示答案怎么办？**
A: 题库 JSON 已预留 `a` 字段。后续只要在 `template.html` 里把该字段渲染出来即可（本期按约定隐藏）。
