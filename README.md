# 知识点复习系统

> 为【需要复习备考的你】，在【手机 / 平板 / 电脑都能用】的场景，解决【题库里有一批考点、想按遗忘曲线安排复习、又怕漏掉没学过的内容】的问题，产出【一个部署在自己服务器上、多账号、多设备同步的知识点复习系统】。

**核心特点**

- 📇 **卡片式复习**：一次一张知识点，心里回忆后自评「认识 / 模糊 / 忘记」
- 📈 **艾宾浩斯阶梯计划**：`1→2→4→7→15→30→60→90→180` 天；认识进档、模糊退档、忘记重置
- 🔔 **到期全部推送**：今日到期的已学知识点不限量列出，不设上限
- 🆕 **30% 未学提醒**：每次复习额外混入约当日期数量的 30% 未学知识点，仅作提醒；**可评价但不计入已学**，需点「加入复习」才转为已学
- 👥 **多账号 + 服务器同步**：注册登录，各账号进度独立，手机平板电脑共用一份进度
- 🎲 **保留随机出题**：自由练习模式，不记录进度
- 📦 **零外部依赖**：只用 Node.js 内置模块（`node:http` / `node:sqlite` / `node:crypto`），无需 `npm install`、无需数据库服务

---

## 技术栈

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 后端 | Node.js ≥ 24（原生 `node:http`） | 零 npm 依赖 |
| 数据库 | SQLite（Node 内置 `node:sqlite`） | 单文件、免安装、易备份 |
| 鉴权 | `node:crypto` scrypt + HttpOnly Cookie 会话 | 密码加盐哈希，注册需口令 |
| 前端 | 原生 HTML / CSS / JS | 响应式，手机平板自适应 |
| 部署 | systemd + 腾讯云服务器 | 开机自启、崩溃自动重启 |

## 快速开始（本地）

```bash
# 1. 导入题库到数据库（读取 data/*.json）
node server/seed.mjs

# 2. 启动服务
REGISTER_CODE=my-code node server/server.mjs
# 打开 http://127.0.0.1:8080/
```

环境变量：

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `PORT` | `8080` | 监听端口 |
| `HOST` | `0.0.0.0` | 监听地址；配合 Nginx 可设 `127.0.0.1` |
| `REGISTER_CODE` | `ask-owner` | 注册口令（**生产环境必须修改**） |
| `DB_PATH` | `<项目>/var/learning.db` | 数据库文件路径 |

## 复习机制说明

### 间隔阶梯

| 自评 | 效果 | 按钮显示 |
| --- | --- | --- |
| **认识** | 前进一档（间隔翻倍式变长） | 如 `2天后` |
| **模糊** | 退回一档 | 如 `1天后` |
| **忘记** | 重置回第 1 档 | `1天后` |

阶梯共 9 档：第1档 1 天 → 第2档 2 天 → 第3档 4 天 → 第4档 7 天 → 第5档 15 天 → 第6档 30 天 → 第7档 60 天 → 第8档 90 天 → 第9档 180 天。

### 今日队列怎么组成

1. **到期已学**：`next_review <= 今天` 的已学知识点，**全部列出、不限量**
2. **未学提醒**：额外混入 `round(到期数 × 30%)` 个未学知识点（今日 0 到期时给 10 个起步）

### 未学 → 已学 怎么转

未学知识点卡片上有一个 **「＋ 加入复习（转为已学）」** 按钮：
- 直接点三档按钮 → 只记录提醒，**不算已学**（仍留在未学池）
- 点「加入复习」→ 转为已学，从第 1 档开始排计划（次日复习）

### 抽题范围

在「我的 → 复习范围」勾选科目并保存；**不勾选 = 全部科目**。该范围同时作用于「复习」和「出题」。

## 部署到腾讯云

完整步骤见 **[`deploy/部署说明.md`](deploy/部署说明.md)**。

一句话版（在本机 Windows 执行）：

```powershell
pwsh -File deploy/deploy.ps1 `
  -ServerHost 你的服务器IP `
  -SshKey "$env:USERPROFILE\.ssh\id_ed25519" `
  -RegisterCode "你的注册口令"
```

脚本会：本地跑测试 → 打包 → 上传 → 服务器上装 systemd 服务并启动 → 验证健康检查。

记得在**腾讯云安全组放行应用端口**（默认 8080），手机才能访问。

## 添加 / 修改题目

```powershell
# 方式 A：改 inputs/*.docx 后重新解析（脚本内含错别字修正与清洗规则）
python scripts/import_docx.py
node server/seed.mjs
pwsh -File deploy/deploy.ps1 -ServerHost 你的IP -RegisterCode "口令" -SkipTests

# 方式 B：直接编辑 data/<科目>.json，再执行上面第 2、3 步
```

> ⚠️ 服务器上更新题库时请用 `node server/seed.mjs --append`，避免清空题库导致用户进度外键失效。

## 功能清单

- [x] 注册 / 登录（注册口令拦截陌生人），多账号进度隔离
- [x] 卡片式复习：题目居中、三档自评按钮显示「X天后」
- [x] 艾宾浩斯阶梯：认识进档 / 模糊退档 / 忘记重置
- [x] 今日到期全部推送、不设上限
- [x] 每次混入约 30% 未学知识点，仅提醒、可评价不转已学
- [x] 「加入复习」手动转为已学
- [x] 复习范围（科目）设置，作用于复习与出题
- [x] 统计页：总题数 / 已学 / 今日待复习 / 累计复习 + 各档分布 + 自评分布
- [x] 随机出题（不记录进度）
- [x] 手机 / 平板 / 电脑响应式，底部导航带到期角标
- [x] 多设备同步（服务器数据库）

### 明确不做

- 不判对错（三档为**自评**，系统不判断答案对错）
- 不做答案自动展示（题库 `a` 字段预留）
- 不做推送通知（网页内"今日待复习"即触发方式）
- 不做记忆曲线以外的算法（如 SM-2 / FSRS）

## 已知限制

- 题库条目多为考点式短语（如"无土栽培"），属原始 docx 数据特征。
- 数据库为 SQLite 单文件，适合个人 / 少量账号；若要多用户高并发需换数据库。
- 「累计复习次数」只统计已学知识点的自评，不含未学提醒的评价。

## FAQ

**Q：为什么点三档按钮后，未学知识点没有变成已学？**
A：这是设计如此。未学知识点只作提醒，需点「加入复习」才转为已学并进入复习计划。

**Q：今日一个到期知识点都没有，怎么办？**
A：系统会自动给你 10 个未学提醒作为起步，你从中挑想学的点「加入复习」。

**Q：换手机后进度还在吗？**
A：在。进度存服务器数据库，用同一账号登录即可看到相同进度。

**Q：需要云服务器吗？能用 GitHub Pages 吗？**
A：本系统需要后端 + 数据库，所以需要一台能跑 Node 的服务器（腾讯云轻量即可）。纯静态的「遗留版本」可以放 GitHub Pages，但不带账号与同步。
