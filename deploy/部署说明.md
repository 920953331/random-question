# 部署说明（腾讯云服务器）

本系统部署到你自己的一台 Linux 服务器上，手机 / 平板 / 电脑通过浏览器访问，学习进度存服务器数据库、多设备同步。

---

## 一、服务器要求

| 项 | 要求 | 说明 |
| --- | --- | --- |
| 系统 | Ubuntu 20.04+ / Debian 11+ / CentOS 8+ | 推荐 Ubuntu 22.04 |
| Node.js | **≥ 24**（必须） | 项目用 Node 内置 `node:sqlite`，无需 MySQL/Redis |
| 内存 | 512MB 起 | 够用，SQLite 很轻 |
| 磁盘 | 1GB 起 | 数据库 + 代码约几十 MB |
| 网络 | 放行应用端口 | 默认 8080，需在**安全组**放行 |
| 权限 | root 或 sudo | 写 systemd 服务需要 |

> **零依赖**：不需要 `npm install`，不需要数据库服务，不需要 Docker。

### 如果服务器上没有 Node 24

```bash
# Ubuntu / Debian
curl -fsSL https://deb.nodesource.com/setup_24.x | bash -
apt-get install -y nodejs

# 验证
node -v          # 应显示 v24.x
node -e "require('node:sqlite'); console.log('sqlite OK')"
```

## 二、一键部署（推荐，在本机 Windows 上执行）

本机已有项目代码时，一条命令搞定：测试 → 打包 → 上传 → 远程安装。

```powershell
cd "E:\AIcoding Projects\random-question"

pwsh -File deploy/deploy.ps1 `
  -ServerHost 你的服务器公网IP `
  -ServerUser root `
  -SshKey "$env:USERPROFILE\.ssh\id_ed25519" `
  -RegisterCode "你自己的注册口令"
```

参数说明：

| 参数 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `-ServerHost` | ✅ | — | 服务器公网 IP 或域名 |
| `-ServerUser` | | `root` | SSH 用户名 |
| `-SshPort` | | `22` | SSH 端口 |
| `-SshKey` | | 默认密钥 | 私钥路径，推荐指定 |
| `-RegisterCode` | ✅ | — | 注册口令（注册账号时要用） |
| `-AppPort` | | `8080` | 服务监听端口 |
| `-SkipTests` | | — | 跳过本地测试 |
| `-DryRun` | | — | 只演练，不真正上传 |

### 先演练一遍（不连服务器）

```powershell
pwsh -File deploy/deploy.ps1 -ServerHost 1.2.3.4 -RegisterCode "demo" -SkipTests -DryRun
```

## 三、手动部署（或服务器上直接操作）

### 1. 本机打包并上传

```powershell
# 打包
tar -czf "$env:TEMP\random-question.tar.gz" server web data deploy package.json README.md docs

# 上传
scp -P 22 "$env:TEMP\random-question.tar.gz" root@你的IP:/tmp/random-question.tar.gz
```

### 2. 服务器上安装

```bash
ssh root@你的IP

rm -rf /tmp/random-question && mkdir -p /tmp/random-question
tar -xzf /tmp/random-question.tar.gz -C /tmp/random-question

REGISTER_CODE='你的注册口令' PORT=8080 \
  bash /tmp/random-question/deploy/install-on-server.sh /tmp/random-question
```

安装脚本会自动完成：检查 Node → 创建目录 → 同步代码 → 导入题库 → 写 systemd 服务 → 启动 → 自检。

## 四、开放端口（必须）

手机 / 平板要访问，必须在**腾讯云控制台 → 安全组 → 入站规则**放行应用端口：

| 类型 | 协议 | 端口 | 来源 |
| --- | --- | --- | --- |
| 自定义 TCP | TCP | 8080（或你设的端口） | 0.0.0.0/0 |

服务器本机防火墙（如果开了 ufw）：

```bash
ufw allow 8080/tcp
```

验证：

```bash
# 服务器本机
curl -s http://127.0.0.1:8080/api/health
# 本机（你自己的电脑）
curl http://你的IP:8080/api/health
```

## 五、使用

1. 手机 / 平板 / 电脑浏览器打开：`http://你的服务器IP:8080/`
2. 点「注册」，填用户名、密码、**注册口令**（就是部署时设的 `RegisterCode`）
3. 注册后即可开始复习；所有设备用同一账号登录，进度自动同步

## 六、可选：Nginx 反向代理 + 域名 + HTTPS

想用域名（如 `https://review.example.com`）或加 HTTPS，可让 Nginx 反代：

```bash
apt-get install -y nginx
```

`/etc/nginx/sites-available/random-question`：

```nginx
server {
    listen 80;
    server_name review.example.com;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

```bash
ln -s /etc/nginx/sites-available/random-question /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx
```

> 配合 Nginx 时，建议让 Node 只监听本机：重新部署时加
> `SERVE_PUBLIC=0`（安装脚本会写 `HOST=127.0.0.1`）。

HTTPS 证书（需域名已解析到服务器）：

```bash
apt-get install -y certbot python3-certbot-nginx
certbot --nginx -d review.example.com
```

> ⚠️ 中国大陆服务器用域名提供 Web 服务需要**域名备案**；直接用 `IP:端口` 访问不需要备案。

## 八、备份与恢复

数据只有两个地方：**数据库**（学习进度 + 题库）和 **data/ 题库 JSON**（源数据）。

### 备份

```bash
# 数据库（先停服务或用 sqlite3 .backup 保证一致性）
systemctl stop random-question
cp /var/lib/random-question/learning.db ~/learning-$(date +%F).db
systemctl start random-question
```

### 恢复

```bash
systemctl stop random-question
cp ~/learning-2026-09-22.db /var/lib/random-question/learning.db
chown root:root /var/lib/random-question/learning.db
systemctl start random-question
```

### 只重建题库（保留用户进度）

不要在已有用户数据时重跑 `seed.mjs`（默认会清空题库）。用追加模式：

```bash
cd /opt/random-question
DB_PATH=/var/lib/random-question/learning.db node server/seed.mjs --append
```

## 九、更新代码

改完题库或代码后，重新执行一键部署即可（会自动重启服务，用户数据不丢）：

```powershell
pwsh -File deploy/deploy.ps1 -ServerHost 你的IP -RegisterCode "口令" -SkipTests
```

> `install-on-server.sh` 同步代码时会排除 `.env` / `var` / `.git`，且**不会删除** `/var/lib/random-question/learning.db`，所以学习进度安全。

修改题库的完整流程：

```powershell
# 1) 改 inputs/*.docx 后重新解析
python scripts/import_docx.py
# 2) 本地重建数据库验证
node server/seed.mjs
# 3) 部署
pwsh -File deploy/deploy.ps1 -ServerHost 你的IP -RegisterCode "口令" -SkipTests
```

## 十、常见问题

**Q：手机打不开网址？**
A：① 腾讯云安全组是否放行了端口；② 服务器 `ufw` 是否放行；③ 服务是否在跑（`systemctl status random-question`）。

**Q：注册时提示"注册口令不正确"？**
A：口令是部署时 `REGISTER_CODE` 设的值。查看当前值：
`grep Environment /etc/systemd/system/random-question.service`

**Q：忘记注册口令了？**
A：改新的口令后重启即可（已有账号不受影响）：
```bash
sed -i 's/^Environment=REGISTER_CODE=.*/Environment=REGISTER_CODE=新口令/' /etc/systemd/system/random-question.service
systemctl daemon-reload && systemctl restart random-question
```

**Q：想改监听端口？**
A：重新部署时指定 `-AppPort 9000`，并同步在安全组放行新端口。

**Q：数据存在哪？会不会丢？**
A：都在 `/var/lib/random-question/learning.db`。部署/更新代码不会动它。建议定期按第八节备份。

**Q：能重置某个账号的进度吗？**
A：可以，删除该用户在 `progress` 表的记录：
```bash
sqlite3 /var/lib/random-question/learning.db "DELETE FROM progress WHERE user_id=(SELECT id FROM users WHERE username='用户名');"
```
（若服务器没有 sqlite3，可 `apt-get install -y sqlite3`）
